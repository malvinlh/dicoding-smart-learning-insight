# Dicoding Smart Learning Insight

Dicoding Smart Learning Insight is a web application that presents personalized **learning style** and **exam performance insights** generated by a **machine learning model**.  
The application also provides an **admin dashboard** for managing insights manually when needed.

## ✨ Key Features
- 🔍 **User ID Lookup** to view personalized insights
- 🤖 **AI-Generated Learning Insight**
- 🧑‍💼 **Admin Dashboard** for insight management
- ✏️ **Manual Insight Management** (add, update, delete)
- 🌗 **Dark / Light Mode**
- 📋 **Copy Insight Report**

## 🧠 Displayed Insights
- **Learning Style**
  - Cluster label
  - Short explanation
  - Personalized learning recommendation
- **Exam & Submission Performance**
  - Cluster label
  - Performance insight
  - Improvement suggestion

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js (Hapi)
- **Database**: PostgreSQL (Neon) 
- **Deployment**: Vercel (single project for frontend & backend)

## 🚀 Deployment
This project is designed to run in **a single Vercel project** using serverless APIs.  
Both frontend and backend share the same domain, enabling seamless API communication.  
The database is hosted separately using **Neon (PostgreSQL)**.

## 📌 Notes
- Insights generated by the machine learning model **cannot be edited or deleted** via the dashboard.
- Manual insights can only be modified if they were created manually.
- All displayed insights are **personal and private**.
